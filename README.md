

##📝 프로젝트 설명 구성안 (포트폴리오/면접용)###1. 🚀 프로젝트 개요 및 문제 정의 (What & Why)**핵심:** 이 프로젝트를 만든 목적과 해결하고자 했던 문제를 명확히 제시합니다.



💡 주요 기능 및 사용자 경험 (Feature & UX)사용자(개발자) 입장에서 매력적인 핵심 기능들을 소개합니다.

* **IDE 모방 UI/UX:** VS Code와 유사한 다크 모드 테마, 개발자 전용 폰트(Monospace)를 사용해 실제 코딩 환경을 재현했습니다.
* **언어별 컨텐츠:** JavaScript, Python 등 언어별 문법과 실제 코드 예제(더미 데이터 사용)를 제공하여 실전 연습이 가능합니다.
* **실시간 피드백:** WPM, 정확도, 소요 시간을 실시간으로 계산하여 사용자에게 즉각적인 성능 지표를 제공합니다.

⚙️ 기술적 도전 과제 및 해결 방안 (Technical Challenges)이 부분이 면접관에게 가장 중요하게 어필해야 하는 부분입니다. 당신이 어떤 어려운 로직을 해결했는지 강조하세요.

####① 입력 처리 및 오타 시각화* **도전:** 브라우저 기본 동작(`Tab`, `Enter`)을 막고(preventDefault), 키보드 입력을 DOM에 직접 렌더링되는 텍스트와 실시간으로 비교해야 했습니다.
* **해결:**
* **바닐라 JS:** `keydown` 이벤트 리스너를 사용하여 모든 입력을 가로채고, 상태(userInput, cursorIndex)를 업데이트한 후, 전체 코드를 다시 렌더링하는 `renderCode()` 함수를 호출했습니다.
* **시각화:** 원본 텍스트와 사용자 입력 텍스트를 인덱스별로 비교하여, 맞으면 흰색, 틀리면 빨간색 스타일을 동적으로 적용했습니다.



####② 자동 들여쓰기 (Auto Indentation) 로직* **도전:** `Enter` 키 입력 시 다음 줄에 IDE처럼 자동으로 **올바른 공백 수**를 계산하여 삽입해야 했습니다.
* **해결:**
* **로직 구현:** `Enter` 발생 시, 직전 줄(`lastLine`)을 분석했습니다. `lastLine`이 **'{'** 또는 **':'** 로 끝났다면 (`problem.tabWidth` 만큼 공백 추가) + (`baseIndent`)를 계산하여 `userInput`에 삽입했습니다.
* **탭 처리:** `Tab` 키를 누르면 브라우저 포커스 이동 대신, 정의된 `tabWidth` 만큼의 공백 문자열을 삽입하도록 처리했습니다.



####③ 통계 및 분석 시스템 (Data Analysis)* **도전:** 정확한 WPM 및 정확도 산출과 함께, 사용자에게 유용한 약점 분석 데이터를 제공해야 했습니다.
* **해결:**
* **WPM 계산:** 정확하게 입력된 문자 수(정확도 로직 활용)를 기반으로 **'분당 단어 수'**를 계산했습니다.
* **약점 분석 (계획):** (계획 단계에서) 특수 문자 오류를 별도로 카운트하여 **괄호/기호 입력에 대한 집중적인 피드백**을 제공할 수 있는 기반을 마련했습니다.



 🔗 기술 스택 (Tech Stack)사용한 기술과 그 이유를 설명합니다.

* **언어/프레임워크:** **바닐라 JavaScript, HTML5, CSS**
* **선택 이유:** 복잡한 상태 관리와 DOM 조작 로직을 순수 JavaScript로 구현함으로써, **프론트엔드 작동 원리와 브라우저 이벤트 처리**에 대한 깊은 이해를 증명하기 위함입니다.


* **디자인:** **Custom CSS** (Tailwind CSS 스타일 컨셉 모방)
* **선택 이유:** 개발자 친화적인 다크모드와 모노스페이스 환경을 직접 구현했습니다.
